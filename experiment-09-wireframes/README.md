# Experiment 09 – Wireframes

**Aim:** Create low-fidelity wireframes for the SCHOLARO scholarship finder.

## Screens
1. Home / scholarship discovery
2. Scholarship search and filters
3. Scholarship details

## Design approach
These are intentionally low-fidelity layouts. They focus on structure, content hierarchy, navigation and placement of controls rather than final colours or visual polish.

## Run
Open `index.html` in a browser. No dependencies are required.
