# Experiment 10 – Create Mockups Using Figma Plugins

**Aim:** Create high-fidelity SCHOLARO mockups using the existing product design language, then import the rendered screens into Figma with a design-import plugin.

## Mockup screens
1. Scholarship discovery home
2. Search and filter scholarships
3. Scholarship details

## Design direction
- SCHOLARO purple and lavender palette
- Rounded cards and controls
- Clear type hierarchy and generous spacing
- Scholarship-specific content for Tamil Nadu students

## Files
- `index.html` – responsive high-fidelity mockup gallery
- `assets/scholaro-mark.svg` – simple SCHOLARO brand mark

## Complete the Figma-plugin part
This repository contains the mockup source. To demonstrate the required Figma plugin workflow:

1. Open the HTML mockup in a browser.
2. In Figma, open the SCHOLARO design file.
3. Open **Resources → Plugins** and search for **HTML to Design** (or an institution-approved HTML-to-Figma import plugin).
4. Run the plugin and follow its current import instructions to import the three screens.
5. Place the imported screens in a section titled **Experiment 10 – Mockups**.
6. Compare the imported result with the browser preview and fix any font or spacing differences.

Plugin availability and import method can change; use the plugin's current instructions. Do not claim the plugin step is complete until the screens are actually imported into Figma.

## Run
Open `index.html` in a modern browser. No dependencies are required.
