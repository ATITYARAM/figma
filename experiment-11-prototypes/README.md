# Experiment 11 – Prototype Using UI Components

**Aim:** Build a clickable SCHOLARO prototype that demonstrates navigation and interaction between UI screens.

## Prototype flow
1. Discover scholarships
2. Open scholarship details
3. Review eligibility
4. View required documents
5. Save a scholarship

## Interactions
- Click a scholarship card or button to navigate to details.
- Switch between Overview, Eligibility and Documents tabs.
- Save and unsave the scholarship.
- Use Back and bottom navigation controls to move between screens.

## Run
Open `index.html` in a modern browser. No dependencies or build step are required.

## Figma practical completion
The HTML file is a runnable companion prototype. To complete the Figma practical, recreate or import the screens into Figma and connect them in the Prototype tab using On Click → Navigate to, plus Smart Animate where appropriate. Test the flow using Present mode.
