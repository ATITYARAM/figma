# Experiment 08 – Micro-interactions

**Aim:** Demonstrate a small, meaningful interaction in the SCHOLARO scholarship interface.

## Interaction implemented

- Save / unsave a scholarship using the heart control.
- The button toggles between an outlined and filled heart.
- The saved state updates its accessible label and status message.
- A short CSS transition provides visual feedback.

## Figma reference

[Open the SCHOLARO Figma file](https://www.figma.com/design/LhLT7B4bFKpFXiMLc8nb1A/Untitled)

The Figma canvas contains the visual Experiment 08 state gallery. The standalone demo in this folder is a runnable companion example; it does not replace the editable Figma design.

## Run

Open `index.html` directly in any modern browser. No dependencies are required.

## Verify

1. Click **Save scholarship**.
2. Confirm the heart fills and the status changes to **Saved**.
3. Click again.
4. Confirm it returns to the unsaved state.

Take one screenshot of the unsaved state and one screenshot of the saved state, or record a short screen capture showing the toggle.
