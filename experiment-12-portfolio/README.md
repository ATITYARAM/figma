# Experiment 12 – UI/UX Portfolio

**Aim:** Present the SCHOLARO UI/UX work in a concise portfolio that communicates the problem, design process, screens, interactions and outcomes.

## Portfolio sections
1. Project introduction – SCHOLARO, Tamil Nadu Scholarship Finder
2. Problem and design goal
3. Design process – research, personas and affinity themes (synthetic exercise data must be labelled hypothetical)
4. Wireframes – discovery, search and scholarship details
5. High-fidelity mockups
6. Micro-interaction – save / unsave scholarship
7. Clickable prototype flow
8. Reflection and next steps

## Run
Open `index.html` in a modern browser. It is a standalone portfolio page with no dependencies.
